# CORA Dataset (Demo Version)

This repository dataset is intended for the CORA — Component Optimization & Recommendation Assistant internship project.

## Files
- PC_Builder_project_(DATA).csv

## Important data note
The prices and several performance/specification values are illustrative demo values for academic development. They are not verified live retail prices or a guarantee of manufacturer compatibility. Verify product specifications against manufacturer documentation before using this system for an actual purchase.

## CSV conventions
- Prices are numeric INR values (no currency symbol or thousands separators).
- Dimensions are in millimetres (mm).
- Power values are in watts (W).
- `supported_sockets` and `supported_form_factors` contain comma-separated values.
- Keep IDs unique within each CSV file.
- Keep category names and technical values consistent (for example: `AM4`, `AM5`, `LGA1700`, `DDR4`, `DDR5`, `ATX`, `mATX`, `ITX`).

## Upload to GitHub
Extract the ZIP, open your `pc-builder-data` repository, choose **Add file → Upload files**, select all 14 CSV files and this README, then commit the changes to your `main` branch.
